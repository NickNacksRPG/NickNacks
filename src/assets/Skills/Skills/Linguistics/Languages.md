# <span style="color:rgb(103, 254, 120)">Common Languages</span>
Languages spoken by large groups of creatures, and interrelated groups.

| Language   | Description                                                                                 |
| ---------- | ------------------------------------------------------------------------------------------- |
| Common     | Pretty much every intelligent creature speaks this unless they are particularly xenophobic. |
| Infernal   | Language of fiends                                                                          |
| Celestial  | Language of celestials                                                                      |
| Sylvan     | Language of fey                                                                             |
| Primordial | The language of elementals and ancient beings                                               |
| Aquan      | The language of sea creatures. Functions underwater                                         |
# <span style="color:rgb(103, 254, 120)">Racial languages</span>
Racial languages are typically named after the race that created them. Names that aren't self evident are put in (parenthesis).
- Goblin
- Giant
- Elven
- Manganese (anime)
- Orc
- Giant
- Draconic
# <span style="color:rgb(103, 254, 120)">Uncommon languages</span>

| Language      | Description                                                                                                                                                                                         |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Morse Code    | A binary code of two sounds mixed to create letters in an alphabet. Communication in Morse code is very slow and impractical, but still serves a useful function for subtle communication.<br>      |
| Sign Language | An entirely visual language that consists of hand gestures that translates directly to common. Other languages can also potentially have their own variant of sign language.                        |
| Necril        | Language of undead                                                                                                                                                                                  |
| Semaphore     | A code that uses the position of flags to create letters in an alphabet. Communication and semaphore is very slow and impractical, but still serves a useful function for subtle communication.<br> |
# <span style="color:rgb(103, 254, 120)"><span style="color:rgb(103, 254, 120)">Ancient Languages</span></span>
Ancient languages aren't as exclusive as secret languages, but are basically not spoken by anybody except history buffs and very old creatures. Requires many bodies of texts or a specialized teacher who already knows the language to learn.

| Language       | Description                                                                                                                                                                                                     |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Ancient Dragon | A particularly old dialect of draconic, spoken only by particularly old creatures that lived during [[1. The Age of Dragons]]. A creature that can understand draconic can only get pick out a few basic words. |
| [[Avese]]      | A language used by ancient druidic space birds. Most sources of avese text are typically etched into stone and preserved with strange magic that applies a thin layer of water.                                 |
# <span style="color:rgb(103, 254, 120)"><span style="color:rgb(103, 254, 120)">Secret languages</span></span>
Secret languages are languages that are actively gated, requiring very special permissions in exclusive clubs and direct teaching to learn. Books are never written in secret languages.

| Language     | Description                                                                                                                                                                                                                                  |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Druidic      | Typically only passed down from teacher to student with specialized training in nature magic.                                                                                                                                                |
| Thieves Cant | The language of thieves and criminals. It's more like speaking in code than another language entirely. Thieves cant can be "fished," allowing you to gauge if someone knows the lingo while speaking another language.                       |
| Bronze       | A unique language that is only understood by creatures with negative intelligence. Typically only spoken by barbarians.<br>                                                                                                                  |
| Fairy Flare  | A language that is only used by a specific type of fairies that cause their bioluminescent antennae to flash in specific patterns. Even if you know the language, it cannot be spoken without the proper biology/equipment, only understood. |
