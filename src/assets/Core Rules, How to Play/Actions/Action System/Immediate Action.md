A Swift Action that can occur off-turn. Limited to one per round, shared with Swift Action — you cannot use both in the same round.

You cannot use an immediate action AND an instant action in response to the same trigger (ie taking the [[Block]] action for yourself and an ally against a [[Kazekenshin]] Steel Tempest.)

Immediate actions, like [[Instant Action|instant actions]], always happen <span style="color:rgb(192, 0, 0)">before</span> the triggering action.
