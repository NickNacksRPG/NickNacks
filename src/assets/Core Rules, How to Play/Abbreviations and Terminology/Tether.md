A tether is some kind of binding effect that connects 2 or more creatures together in a way that is usually represented by some kind of visible chain or string of energy. Some tether effects happen willingly, others happen unwillingly.

Tethers usually have some kind of specified range that their effect can be applied, and then a wider area that the effect can persist in afterwards, like [[Shackles of Pain]]. Usually the stipulation is that if you move out of this range, the tether breaks, but some tethers are physical objects, like with [[Bondage]] and have some kind of push and pull element to them.
